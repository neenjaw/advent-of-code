# Rust Advent of Code day template

A copied day is a self-contained Cargo project with no third-party
dependencies.

## Requirements and commands

Install Rust 1.78 or newer and Cargo. Run commands from this directory:

```sh
# Run the tests
cargo test

# Run with input.txt
cargo run

# Run with a different input file
cargo run -- samples/part1.txt
```

The personal `input.txt` is ignored by Git; sample fixtures under `samples/`
remain trackable.

## Files

```text
src/main.rs       # Input-file handling and answer output
src/solution.rs   # Puzzle logic and sample tests
samples/          # Trackable sample inputs
input.txt         # Your personal puzzle input (ignored)
Cargo.toml        # Project configuration and dependencies
Cargo.lock        # Resolved dependencies (generated by Cargo)
```

## Solution interface

Implement puzzle logic in `src/solution.rs`. Each part receives the complete
raw input as `&str` and returns its answer as a `String`:

```rust
pub fn part1(input: &str) -> String {
    // Parse and solve Part 1
}

pub fn part2(input: &str) -> Option<String> {
    // Return Some(answer) when this day has Part 2.
    // Return None when there is no second part.
}
```

The runner owns file I/O and printing. It reads `input.txt` by default or
accepts a path after `--`, then prints labeled answers. Unit tests call the
solution functions directly and load their own sample fixtures, so the parts
can use different examples. Replace the demonstration logic, fixtures, and
expected answers with the day's puzzle.

Add dependencies to this day's `Cargo.toml` only when needed. Cargo records
resolved versions in `Cargo.lock`; commit it with the day to keep dependency
resolution reproducible.
